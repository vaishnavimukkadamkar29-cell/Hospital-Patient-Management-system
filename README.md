# 🏥 Smart Hospital Patient Management System

## 📌 Problem Statement
Patients often do not know which doctor or department to consult based on their symptoms. This leads to incorrect appointments, long waiting times, and inefficient hospital workflows.

## 🎯 Objective
To build a smart web-based system that automatically assigns patients to the appropriate medical specialist based on symptoms and manages appointments using a digital token system.

## 💡 Features
- Symptom-based doctor assignment
- Automatic specialist selection
- Appointment booking with valid date & time
- Digital token generation
- Prevents booking past dates
- Simple and user-friendly UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Download or clone the repository
2. Open `index.html` in a browser
